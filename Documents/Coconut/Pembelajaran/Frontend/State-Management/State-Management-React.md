STATE MANAGEMENT REACT
- Teknik/cara untuk menyimpan, memperbaharui, dan membagi data secara dinamis diseluruh diseluruh komponen aplikasi agar UI tetap konsisten.

STATE
- Event Handling
  Respon jembatan antara user dan website. Interaksi yang dilakukan oleh pengguna seperti klik tombol, menggeser mouse, input keyboard, dll.
- Usestate
  Sebuah penyimpanan untuk menyimpan data yang bisa berubah-ubah dimana saat setiap kali data/inputan berubah, tampilan infrmasi atau website akan langsung berubah secara otomatis.
- Usereducer
  Sebuah penyimpanan state untuk aplikasi yang lebih kompleks, dimana state akan menjadi lebih terprediksi dan terukur.
