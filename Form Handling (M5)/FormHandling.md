FORM HANDLING
-Proses mengelola data yang dimasukkan ke pengguna melalui form

Teknik Pendekatan Form Handling
-Controlled Form -> Input dikontrol penuh oleh react state
-Uncontrolled Form -> Input dikontrol oleh DOM itu sendiri
-Form Validation -> Proses memverifikasi bahwa data yang dimasukkan pengguna memenuhi aturan yang ditetapkan sebelum data diproses atau dikirim.
-Handling Complex form (Multi Input Form) -> Teknik ini digunakan saat menangani form yang memiliki banyak inputfield, atau bahkan memerlukan input fields yang dinamis.
-Headling Form Dinamis (Dynamic Form) -> Membuat form yang strukturnya dapat berubah sesuai dengan kondisi tertentu. Contohnya formasi registrasi yang memiliki input tambahan jika user memilih "ya" pada input "apakah anda memiliki anak"
